# Best practices — UX heuristics (for wizard & artifact design)

`tier: advisory` · seed (unverified). Refresh via `/refresh-forge-kb` (source: Nielsen Norman
Group).

Applied to designing the wizard's interaction and any artifact that talks to a person:

- **Visibility of system status.** Always show where the user is in the flow (phase, what is
  DEFINED vs PENDING). The HTML approval view exists for this.
- **Match to the real world.** Explain dependencies and errors in plain terms, not command
  names or error codes.
- **User control & freedom.** Confirm before irreversible actions; make it easy to go back and
  change a definition.
- **Error prevention over error messages.** The Ledger blocks generation before a hole becomes
  a broken artifact.
- **Recognition over recall.** Offer suggestions (clearly labeled) so the user recognizes a
  good answer instead of recalling one — but never let a suggestion become an assumption.
- **Help users recover from errors.** When verification fails, state which file and why, in
  plain language.
